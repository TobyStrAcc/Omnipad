Support & quick fixes

Install OmniPad as an app

Chrome or Edge (recommended): look for the install icon ⊕ in the address bar — it appears as a small computer-with-arrow icon on the right side. Click it, then Install. OmniPad opens in its own window with no browser chrome, and gets a taskbar / Start menu shortcut.

If you don't see the icon, click the button below:

Safari (iPhone / Mac): tap the Share icon → Add to Home Screen (iPhone) or Add to Dock (Mac). Safari doesn't support the automatic install prompt.

Already installed? Your app icon opens OmniPad in standalone mode. You can safely close this browser tab.

Moving data from a previous install

Browser storage is per origin. If you were using OmniPad from a local file (file://) or a different URL, your data won't appear automatically — you need to export and re-import it.

  1. Open the old version → cog → Data → Export JSON → save the file.
  2. Open this version → cog → Data → Import JSON → pick the file → confirm.

After importing, use this installed app as your single home. The old tab / local file can be discarded.

Getting updates

OmniPad updates automatically — no action needed. When a new version is pushed to GitHub:

  • Installed app users — a green “New version available” banner appears at the top. Click Reload to update.
  • Browser-tab users — same green banner, or force a check: cog → Data → Check for updates.

If the app feels stuck on an old version: Ctrl+Shift+R inside the app window to hard-reload past the cache.

Keyboard shortcuts
  • Enter in the add bar — create action
  • Enter on a row — edit the action text
  • Delete on a row — delete prompt
  • Click status pill — next status · Shift+Click — previous
  • Double-click a row — open full action detail card
  • Right-click a row — context menu (priority, status, due date, delete)
  • Ctrl+K — global search · Ctrl+Shift+K — quick capture (URL / action / note)
  • Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4 / Ctrl+5 — switch Actions / Notes / Links / 1-2-1s / Crib
  • Ctrl+B / Ctrl+I / Ctrl+U — bold / italic / underline in notes
  • Tab / Shift+Tab in a note list — indent / outdent
Backups & data safety

The app takes a full snapshot once per day, kept for 14 days. Open History (clock icon) to browse them — restore any day, or download as JSON.

Snapshots live in your browser's localStorage. For an off-device backup, export a JSON file occasionally via cog → Data → Export JSON.

About & privacy

OmniPad is a local-first PWA hosted on GitHub Pages. Everything — actions, notes, projects, comments, backups — lives in your browser's localStorage on this device. Nothing is sent to a server.

The only network calls are to GitHub (to serve the app and check for new versions). No telemetry, no analytics, no accounts.
